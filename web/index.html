        Cómo se construye este mapa

        De un Excel de la Contraloría a esta página, sin servidores ni pagos. Baja para ver cada paso; la terminal muestra la salida real de la última carga.

        obra-parada
        1. gob.pe
        2. Python
        3. dbt + DuckDB
        4. Web
        1. 1

          Descarga

          Cada lunes un workflow de GitHub Actions busca en gob.pe el último informe de obras paralizadas y descarga el Anexo 02. Si el archivo no cambió (mismo SHA-256), se detiene ahí.

        2. 2

          Lectura del Excel

          El Excel cambia de columnas entre un informe y otro. El parser busca la fila que parece cabecera y reconoce cada columna por su nombre, aunque venga con tildes, abreviada o en otro orden.

        3. 3

          Limpieza y validación

          dbt sobre DuckDB tipa los datos, ubica cada obra en su distrito con el ubigeo del INEI y corre tests: avance entre 0 y 100, saldo menor que el costo, totales que cuadran. Si algo falla, no se publica.

        4. 4

          Publicación

          Los modelos finales se exportan a JSON y se commitean al repo. Netlify publica el sitio estático; el navegador hace todos los filtros, sin base de datos en línea.

        De dónde salen los datos

        Del Informe de obras paralizadas en el territorio nacional de la Contraloría, Anexo N.° 02. La Contraloría considera paralizada una obra que no registra avance físico por seis meses o más en Infobras.

        Lo que esta página no dice

        No acusa a nadie. Una obra puede pararse por un arbitraje, un huaico o falta de presupuesto. Los montos son los que reportan las propias entidades y pueden tener errores; ante una duda, manda la fuente oficial.
