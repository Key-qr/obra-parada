            Cómo se construye este mapa

            De un Excel de la Contraloría a esta página, sin servidores ni pagos. Baja para ver cada paso; la terminal muestra la salida real de la última carga.

            obra-parada
            1. gob.pe
            2. Python
            3. dbt + DuckDB
            4. Web
            1. 1

              Descarga

              Cada lunes un workflow de GitHub Actions busca en gob.pe el último informe de obras paralizadas y descarga sus dos bases: el Anexo N.° 01 (la lista de obras) y el Anexo N.° 02 (los servicios de control). Si el archivo no cambió (mismo SHA-256), se detiene ahí.

            2. 2

              Lectura del Excel

              El Excel cambia de columnas entre un informe y otro. El parser busca la fila que parece cabecera y reconoce cada columna por su nombre, aunque venga con tildes, abreviada o en otro orden.

            3. 3

              Limpieza y validación

              dbt sobre DuckDB tipa los datos, ubica cada obra en su distrito con el ubigeo del INEI y corre tests: avance entre 0 y 100, saldo menor que el costo, totales que cuadran, cada servicio de control apunta a una obra de la lista. Si algo falla, no se publica.

            4. 4

              Publicación

              Los modelos finales se exportan a JSON y se commitean al repo. GitHub Pages publica el sitio estático; el navegador hace todos los filtros, sin base de datos en línea.

            De dónde salen los datos

            Del Informe de obras paralizadas en el territorio nacional de la Contraloría: Anexo N.° 01 (lista de obras) y Anexo N.° 02 (servicios de control). La Contraloría considera paralizada una obra que no registra avance físico por seis meses o más en Infobras.

            Lo que esta página no dice

            No acusa a nadie. Una obra puede pararse por un arbitraje, un huaico o falta de presupuesto. Los montos son los que reportan las propias entidades y pueden tener errores; ante una duda, manda la fuente oficial.

            Anexo N.° 02 · Servicios de control

            Lo que la Contraloría revisó en las obras paralizadas

            Cada fila de esta base es un servicio de control hecho a una obra de la lista: un control concurrente, una visita, una orientación de oficio, una auditoría. Todos figuran como concluidos y la mayoría tiene su informe publicado.
